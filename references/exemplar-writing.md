# 范文学习规范：L1—L4写作与认识分析

用户可以提供一篇或多篇参考文献作为“写作范文”。范文同时进入文献池的收录流程，但在具体写作中仍要区分三种功能：范文回答“怎样写”，文献池中已核验的理论回答“用什么理论”，田野材料回答“凭什么论证”。

## 四层分析总则

范文分析不是单一的“风格模仿”，而是四个相互关联但来源资格不同的层级：

| 层级 | 核心问题 | 默认输出 | 存储位置与资格 |
|---|---|---|---|
| L1 | 作者在句子和词语层面怎样写 | 语言DNA | 写作画像；不是理论来源 |
| L2 | 文章怎样搭建并推进 | 文章结构模板 | 写作画像；不是理论来源 |
| L3 | 作者怎样看问题，又怎样逐步写出这一认识 | 整体认识＋认识推进脚本 | 文献记录中的作者问题框架/作者命题，并进入写作画像 |
| L4 | 作者在与谁对话，又怎样把理论对话写进论证 | 对话理论＋理论进入脚本 | 理论对话地图与原典导航，并进入写作画像；原著核验后才能直接调用 |

一次分析应尽量覆盖四层，但用户只要求其中一层时可缩减。不同文体的指标允许调整，不能为了填满模板而制造判断。

## L1：语言DNA

逐篇分析的结果按[写作资源库](writing-library/README.md)分别进入词汇、句式和专有名词分库。抽象语言画像不能代替逐条来源记录。

### 分析对象

- 词汇：实词、概念词、过程性动词、判断词、限定词、连接词和高频固定表达；
- 句子：平均句长、中位句长、长短句分布、分句数量、主从结构和句首组织方式；
- 标点：逗号、分号、冒号、括号、引号、破折号等的相对使用习惯；
- 修辞：比喻、设问、对比、否定转折、排比、递进、回环和概念重述；
- 语气：断言、推测、限定、保留、批评和阶段性小结；
- 段落语言：田野叙述、理论综述和作者分析之间的词汇、时态及句法切换。

### 统计与证据规则

- 先说明统计范围：全文、正文、特定章节或抽样段落；参考文献、脚注、摘要是否排除必须注明。
- 词频应同时给出原始次数和必要时的标准化频率，并区分概念性高频与“的、了、是”等功能词。
- 句长须说明以汉字数、字符数还是分词数计算；中文默认报告去除标点后的字符数，另给中位数和分位区间，避免平均数被少数长句支配。
- 扫描件、OCR错乱或文本提取缺页时，将定量结果标为“近似/样本统计”，不得声称是全文精确值。
- 修辞和常用表达应附短例及位置，但不收集大段原文，不把偶然出现一次的句式判为稳定DNA。
- 区分题材导致的词频与作者风格。例如“仪式”“村落”高频可能来自研究对象，不必然是语言偏好。

### 默认输出：语言DNA

```text
统计范围与可靠性
→ 高频词群与概念密度
→ 句长和句法节奏
→ 标点与段落呼吸
→ 转折、限定和判断方式
→ 修辞偏好及回避项
→ 田野/理论/分析三种语域如何切换
→ 可迁移语言规则
→ 不应复制的高辨识度表达
```

语言DNA应转写成可执行规则，如“田野段落多用动作动词，分析段落才提高概念密度”，不能只用“严谨、细腻、学术性强”等空泛形容词。

## L2：文章结构模板

完整原段的逐句功能和句间承接按[段落库](writing-library/paragraph-patterns.md)记录。文章层级结构与段落内部组织分别分析。

### 分析对象

- 开头怎样制造问题：场景、悖论、文献缺口、概念争议或研究史进入；
- 文献综述怎样分类：按作者、阵营、问题、历史阶段还是解释机制；
- 正文怎样分层：时间链、空间链、行动者链、仪式过程、概念链或比较结构；
- 材料、概念与作者判断以何种顺序出现；
- 论证怎样转折和推进：补充、反例、尺度转换、因果收紧、概念修正或竞争解释；
- 各节如何收束并将问题转交下一节；
- 结尾是概括发现、返回理论、限定边界、提出贡献还是规范性升华。

### 默认输出：文章结构模板

```text
开头入口
→ 研究缺口/经验困惑
→ 总问题与材料说明
→ 正文模块及每模块功能
→ 段落级论证动作序列
→ 材料—理论—判断的排列规律
→ 主要转折节点
→ 结尾收束方式
→ 可替换槽位
→ 依赖原案例、不可照搬的结构
```

模板应使用抽象功能槽位，例如“呈现一个违背既有解释的案例”，不得复制范文的标题、案例顺序或独特段落设计。

## L3：整体认识

### 分析对象

- 文章实际面对的经验问题与学术问题；
- 作者选择什么作为分析单位，忽略或排除什么；
- 整体切入视角：实践、过程、结构、历史、情感、身体、物、空间、时间、权力等；
- 总体逻辑是因果、机制、解释、谱系、比较、类型还是规范评价；
- 文章成立所依赖的认识论前提和证据观；
- 最终结论、贡献声称、适用范围和未处理的替代解释。

L3还必须分析这种整体认识怎样在文本中被制造出来，而不能只在读完后概括结论：作者先让读者看到什么经验现象或理论困难；怎样通过命名、分类和尺度选择把现象变成问题；哪些材料承担铺垫、转折或证明；何时从描述转入解释；阶段性结论怎样被下一节继承、修正或扩大；结尾怎样回收开头并把案例判断转成学术贡献。

### 默认输出：整体认识

```text
作者面对的问题
→ 切入视角和分析单位
→ 总体逻辑链
→ 核心结论
→ 作者原创命题/经验概括
→ 认识前提与证据标准
→ 解释增量
→ 盲点、跳跃和适用边界
```

另附一条**认识推进脚本**：

```text
先呈现或排除什么
→ 再界定什么
→ 接着放入哪类材料
→ 在何处发生解释转折
→ 如何形成阶段性结论
→ 怎样累积为全文认识
→ 结尾如何限定并回收贡献
```

该脚本属于可学习的写作形式。复用时只迁移论证功能和顺序，不复制原案例、结论、措辞或高辨识度段落序列。

### 入库规则

- L3进入该范文的文献记录，标注为`作者问题框架`、`作者命题`或`经验性概括`。
- L3的认识推进脚本同时进入写作画像，供后续按论证功能顺序检索和迁移。
- 若作者命名一种理念转型，可作为二手学术史判断记录；不能仅据其命名建立已核验的`intellectual-turn`原典记录。
- 作者自创概念可用于讨论这篇文献及相近经验案例，但不得冒充其所引用理论家的观点。
- L3可以帮助检索理论池，因为它揭示了问题结构；它本身不会自动赋予作者观点以通用理论资格。

## L4：对话理论

### 分析对象

逐项区分文章与文献、理论、概念和思想的关系：

- `background`：仅提供背景、常识或研究史位置；
- `borrow`：借用概念或分析工具；
- `agree`：明确赞同或以其为前提；
- `extend`：迁移、扩展、重组或操作化；
- `revise`：保留核心但修正适用边界或机制；
- `criticize`：指出不足、反例或理论盲点；
- `reject`：明确反驳核心命题；
- `compare`：并列比较但未选择立场；
- `citation-only`：只出现在注释/参考文献，正文没有实质对话。

不能仅凭参考文献表判断作者“赞同”某理论。应定位概念进入的段落、引文周围的评价词、后续是否操作化，以及结论是否回收该理论。

### 理论对话的写作过程

除立场分类外，还要还原理论怎样进入文章并推动作者主张：

1. **进入前任务**：作者先铺陈案例、提出缺口、界定概念还是制造反例；
2. **进入方式**：理论以定义、综述、引文、比较对象、论敌、方法工具或脚注资源出现；
3. **首次功能**：理论第一次出现是帮助看见材料、命名机制，还是提供需要被检验的预期；
4. **材料处理**：作者随后用哪些细节支持、摩擦、拆分或改写该理论；
5. **理论转换**：原概念经过删减、扩展、改名、跨尺度迁移或与其他概念重组后变成什么；
6. **作者主张形成**：理论与案例经过几轮往返后，作者在哪个位置提出自己的判断；
7. **回收方式**：结尾是否说明补充、修正、边界或新概念；没有回收时记录为未完成的理论对话。

### 默认输出：对话理论

| 对话对象 | 原始出处 | 进入位置 | 关系类型 | 作者保留什么 | 作者改变/反驳什么 | 使用的案例或证据 | 原典状态 |
|---|---|---|---|---|---|---|---|

表后补充：主要论敌、主要盟友、概念迁移链、未被作者回应的相邻理论，以及需要补入理论池的原著。

再输出一条**理论进入脚本**：

```text
材料或争论先行
→ 理论为何在此处进入
→ 理论建立什么预期
→ 案例怎样支持或打破预期
→ 作者如何改造概念
→ 新命题怎样出现
→ 结论如何回收与原理论的关系
```

同一文章有多条理论线时分别建立脚本，再判断哪条承担主论证，哪些只是辅助解释。不得把所有引文压缩成一条虚假的统一链。

### 入库规则

- 已在理论池且原著核验的概念：建立与现有理论记录的关系。
- L4的理论进入脚本同时进入写作画像，记录理论如何由文献综述进入案例、再返回作者主张。
- 范文借用并改造的概念：建立概念应用卡，分别记录原作者与应用作者。
- 只在范文中转述、尚无原著的概念：进入原典缺口与二手导航，状态标记`待核验`。
- 范文明确反驳或修正某理论时，记录其证据和修正幅度；不能把应用案例的一次摩擦写成原理论已被普遍推翻。

## 先识别用户要模仿的层面

若用户没有特别指定，默认提取以下高层特征：

- 文章类型与面向的学术读者；
- 研究问题如何被提出；
- 文献综述如何组织争论；
- 理论概念在何处进入；
- 材料段落与分析段落如何交替；
- 论证推进、转折与反论证的节奏；
- 章节层级、段落功能和结尾收束方式；
- 引用密度、注释方式和语体。
- 句法长度、概念密度、转折方式、限定语气与段落收束习惯。

把这些特征按L1—L4分别整理，再用用户材料和文献池内容填充。不得把四层压成笼统的“风格像”。

## 学习论证方式与语言

范文学习必须覆盖两个层面，而不只模仿目录：

### 论证动作

识别每个段落实际完成的工作，例如提出经验困惑、拆解既有命题、界定概念、呈现反例、转换分析尺度、从材料提炼机制、与理论建立张力、提出修正命题、限定适用范围或回收贡献。生成新稿时复用这些抽象论证动作，但由新材料决定动作顺序和篇幅。

### 语言画像

提取可迁移的总体语言特征，例如：

- 经验叙述与概念分析的比例；
- 长短句分布及句内层次；
- 概念首次出现时如何界定；
- 如何使用转折、递进、回指和阶段性小结；
- 判断的确定程度，以及如何表达限制和推断；
- 是否偏好过程性、关系性或机制性的动词；
- 理论术语与田野原话如何并置。

生成时应达到“同类学术语体和论证节奏”，不追求逐句相似。避免反复复制范文中特有的句式组合、标题措辞、比喻或高辨识度表达。

语言形式必须服从内容关系。不要把范文中偶尔出现的修辞手段误判为固定模板：

- 不为制造气势而连续使用排比、三分结构或成串近义词；只有材料确有多个并列机制且并列能改善理解时才使用。
- 不把“不是……而是……”“既非……亦非……”当作默认句型；只有确需排除两个容易混淆的解释时才使用，并在后文给出证据。
- 不机械使用“从……转向……”“不仅……更……”等递进套语；转折强度应与论证中的实际差异相符。
- 避免每段都以抽象判断开头、以宏大意义结尾。根据段落功能在场景、证据、概念、反例或限定之间变化。
- 句子长度随信息负荷调整。一句话只承担一个主要判断；复杂关系需要分句或分段，不用长句掩盖证据缺口。
- 概念只在产生分析增量时使用。若普通词可以准确表达，就不以理论名词增加虚假的学术密度。

完成初稿后做一次“修辞去惯性”检查：搜索重复连接词、对称句、三项并列和二元否定句。逐处判断它们是否由内容要求；没有分析功能的，改成直接陈述。

## 来源隔离

- 范文默认按文献池维护规范提取、核验和编目；若用户明确要求仅作一次性范文，则不持久收录。
- 范文作者针对自身材料提出的观点、概念和经验性概括只属于范文内容，不得作为新文本的理论来源。
- 范文引用或转述的其他学者观点只用于定位候选原著；必须取得并核验原著后，才能用于新文本的实质性理论论证。未核验时标记为“范文中的二手综述/待核验”，不得借引范文代替原典。
- 新文本中的每个理论命题仍须追溯到理论池；每个经验判断须追溯到用户材料。
- 范文自身的观点不能改写后冒充用户的原创发现。

## 原创边界

仿照结构、抽象论证动作与一般学术语体，不复刻可识别句子、特色比喻、独特标题或段落序列。除必要且适度的正式引用外，使用全新的表达。若用户要求高度贴近特定在世作者风格，改为描述并采用较宽泛的学术特征。

## 生成流程

1. 按文献池规范登记范文，并标明已实际阅读和核验的范围。
2. 完成L1语言DNA，并注明语料范围、清洗方式和可靠性。
3. 完成L2文章结构模板与段落级论证动作序列。
4. 完成L3整体认识及认识推进脚本；将作者观点、经验概括和可能的理念转型分别标记，同时记录这些认识按什么顺序被论证出来。
5. 完成L4对话理论及理论进入脚本；区分背景、借用、赞同、扩展、修正、批评、反驳和仅列引用，并记录理论进入—案例处理—作者命题—结尾回收的过程，建立原典缺口。
6. 从理论池中选择已核验原典作为候选理论，完成解释—摩擦—修正分析；范文作者自己的观点不得进入上游理论列表。
7. 建立“范文段落功能 → 新文本内容”的映射，而非逐句改写。
8. 先用新材料写出论证骨架，再按L1语言DNA调整概念密度、转折节奏与段落收束；语言画像不得覆盖材料本身的逻辑。
9. 生成原创稿，并对资料可证实、分析推断和待验证内容保持区分。
10. 执行修辞去惯性检查，删除没有分析功能的排比、对称和二元否定句。
11. 附简短来源说明：理论原典来自哪里、材料来自哪里、范文影响了哪些写作特征。论文体交付默认用脚注直接标注原典。

## 默认交付

除非用户指定篇幅或体裁，先交付：

- L1语言DNA；
- L2文章结构模板；
- L3整体认识与认识推进脚本；
- L4对话理论与理论进入脚本；
- 建议采用的理论及理由；
- 一份可继续修改的学术写作初稿；
- 来源与待补证清单。
