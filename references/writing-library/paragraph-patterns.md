# 段落库：逐句功能与内部组织

段落条目以范文中的完整自然段为单位。先确认原段边界与出处，再逐句说明本句接住前句的什么、增添哪项事实或判断，以及怎样把问题交给下一句。段落库记录**组织方法**；具体句法回到[句式库](sentence-patterns.md)。一个段落可兼有叙述、比较、解释和限定，不能强行压成一种固定顺序。

## 私有条目模板

| 字段 | 记录内容 |
|---|---|
| 编号与主要任务 | `PAR-001`；本段具体回答什么问题 |
| 完整原段与边界 | 私有库保存全文；核对段首、段尾、跨页续接、脚注与图注 |
| 来源定位 | 作品、版本、页码及段落位置；原段内各句的`SEN`编号 |
| 前文已知 | 作者进入本段前已经交代的对象、争论或材料 |
| 逐句功能 | 每句的事实、引语、解释、比较、理论、限定或判断作用 |
| 句间承接 | 回指对象、因果或比较关系、前句新增信息如何被后句使用 |
| 本段结论 | 原段实际推出什么，材料能够支持到哪里 |
| 后文交接 | 本段留下什么问题，下一段怎样接续；没有则写“无” |
| 可迁移组织 | 只抽象内容顺序及适用条件，不复制原段的案例和判断 |
| 不适用条件 | 哪些材料不足以支撑同样的推进顺序 |
| 核验状态 | 已核原段、边界待核、待核 |

逐句表与原段同存：

| 句序与`SEN`编号 | 本句工作 | 接住前句的对象 | 新增事实或判断 | 交给后句的内容 |

| 2 |  |  |  |  |

## 按段落任务检索

下表是检索入口，表示需要寻找哪类**有来源的原段**，不是已经核验的范文条目，也不是写作时必须遵守的句序。

| 段落任务 | 拆解时重点检查 |
|---|---|
| 提出问题 | 经验现象怎样进入，作者在哪一句把它转为可讨论的问题 |
| 现场叙述 | 人物、动作、物件和时间怎样依次进入，哪些细节支撑后面的判断 |
| 比较分析 | 比较对象和共同问题何时明确，差别怎样被解释，结论限于什么范围 |
| 概念界定 | 概念来源、构成、可观察条件和使用边界怎样接续 |
| 文献与理论对话 | 前人命题、案例材料、摩擦或支持、作者判断怎样相互推进 |
| 段落收束 | 前句的材料和分析怎样汇成有限结论，段末是否增加了新的主张 |
| 章节目承接 | 已有结论与后续问题之间的具体关系怎样建立 |

选择段落组织时，先确定当前材料能支持哪些句子，再参考同任务的多个原段。逐句检查回指是否有明确对象，分析是否由前面的材料推出，段末是否重复前句。公开版只给出拆解框架；完整原段与逐句注释保存在使用者的私有库。
