# 词汇库：普通表达及其使用条件

收录从获准使用的范文中核验过的过程动词、关系动词、限定语、连接词和判断词。以具体词形为单位，记录它在原句中做了什么。研究对象名称、作者自创概念和学科术语进入[专有名词库](technical-terms.md)；完整句法进入[句式库](sentence-patterns.md)。

## 条目模板

| 字段 | 记录内容 |
|---|---|
| 编号 | `VOC-001`起，保持稳定 |
| 词形与词性 | 原文实际出现的词；动词、名词、副词、连词等 |
| 原句中的位置 | 句首、谓语、宾语、限定成分或句间连接 |
| 表达功能 | 叙述行动、说明关系、比较、限定、转折、收束等 |
| 语气与搭配 | 判断强弱、常见主语和宾语、是否依赖前句 |
| 原句编号与定位 | 对应`SEN`编号；私有记录中的作品、版本、页码或段落 |
| 观察范围 | 全文或哪几页；次数与统计口径；未统计时不称“高频” |
| 使用条件 | 需要什么事实关系；哪些对象或语境不适合 |
| 核验状态 | 已核原句、部分阅读、待核 |

同一词在不同语境承担不同功能时分开记用法，并保持可回到原句的定位。词汇不能单凭出现次数入库，候选词还须说明为什么比近义词更适合当前句子的工作。写作时先有事实与句子功能，再选词；不以词语堆叠代替分析。
