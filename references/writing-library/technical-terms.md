# 专有名词库：术语、译名与归属

收录有明确作者、文本或学术传统归属的概念词，以及需要原文定位的专门名称。普通动词、连接词和限定语放入[词汇库](vocabulary.md)。某词在范文中出现，不等于新研究可以直接采用它的原有定义或判断。

## 条目模板

| 字段 | 记录内容 |
|---|---|
| 编号 | `TERM-001`起，保持稳定 |
| 原词与译名 | 原文词形、直译、采用译名；多种译法分列 |
| 类型与提出者 | 作者概念、借用概念、学科术语或地方用语；分别写明提出者与使用者 |
| 定义与位置 | 原作者怎样界定；原著版本、页码或段落 |
| 范文中的作用 | 作者用它命名对象、分类、解释机制、比较还是修正前人 |
| 来源资格 | 已核原著、只见于范文、二手转引或用户笔记 |
| 可用范围 | 在哪些问题、对象与证据条件下使用；何处需保留原文说法 |
| 与普通词关系 | 同形普通词是否另记于`VOC`，避免把日常用词当成理论命题 |
| 核验状态 | 已核原著、已核范文但原著待核、待核 |

范文作者使用别人的概念时，原作者的命题和应用作者的改写分开记录。原著未核验时，条目只用于检索和辨认范文写法；理论命题的引用资格依[文献池维护规范](../knowledge-base-format.md)判断。用户研究中的专用称谓也须标明来自田野、用户决定还是文献，不从范文自动迁移。
