# 句式库：完整原句与可迁移母句

一条句式至少对应一条已定位的完整原句。原句是作者实际写出的整句；母句是从该原句提炼的完整可迁移句法。母句应保留真实的连接方式、语序、判断强度和必要的后续分句，并用`［名词短语］`、`［动词短语］`、`［时间短语］`等标明替换位置。短语、半句和事后拼接的句子不能标作完整原句。

## 私有条目模板

| 字段 | 记录内容 |
|---|---|
| 编号与功能 | `SEN-001`；该句承担叙述、举证、分析、比较、限定、承接或收束中的具体工作 |
| 完整原句 | 逐字核对的原句，保留原标点；只放在获准使用的私有库 |
| 来源定位 | 作者、作品、版本、页码或段落；原文文件及可复核的位置 |
| 母句 | 可迁移的完整句式；替换位使用词性或短语类型槽位 |
| 实际保留 | 主干、语序、关联词、语气及分句之间的关系 |
| 抽去与替换 | 原文人物、对象、专有概念、评价及理论判断各怎样处理 |
| 变体关系 | 同一原句的主干式与细分式共用来源编号；多条原句不得合成一条假原句 |
| 使用条件 | 该句法要求怎样的材料关系、前文信息和推断范围 |
| 核验状态 | 已核原句、部分阅读、待核 |

## 调用检查

先列出新句要完成的工作，再检索同功能母句。写成新句后逐项核对：完整原句是否确实存在，母句是否保留原句的主要句法，新词是否来自词汇库或当前材料，句子表达的事实和理论是否各有独立出处。一次写作的逐句对照另存，格式见[逐句出处记录](../sentence-provenance.md)。没有合适原句时继续检索原文，不能只凭功能相似给新句配编号。
