# 写作资源库

本库有四个相互关联的分库：[词汇库](vocabulary.md)、[句式库](sentence-patterns.md)、[专有名词库](technical-terms.md)和[段落库](paragraph-patterns.md)。前三库分别处理常用表达、完整句法与有特定出处的术语；段落库处理一个段落中各句怎样接续。它们与[文献池](../knowledge-base-format.md)的理论命题记录分开。

## 建库顺序

1. 登记获准阅读的范文、版本、实际阅读范围及可定位的页码或段落。来源未核验时，条目标为`待核`。
2. 从原文提取词、完整句和完整原段。先保留原文及其位置，再归纳词语用法、完整句式或段落组织。不要事后为概括配出处。
3. 将可迁移的普通词放入词汇库，将作者或领域的专有术语放入专有名词库。完整句与可迁移母句进入句式库；完整段落及逐句功能进入段落库。
4. 使用时先确定当前论点、材料和段落职责，再选择段落组织、句子功能、母句与词汇。另按[逐句出处记录](../sentence-provenance.md)核对新句与原句、事实与理论的来源。

## 共同字段

每条有稳定编号、功能、原文定位、核验状态、可迁移内容及使用条件。来源定位至少包括作品或文件、版本、页码或可复核的段落位置。一个原句或原段可对应多个功能，但要保留同一个原文编号，避免重复计数。原句支持表达形式，材料和理论的证据仍须另行核对。

## 公开与私有

公开版提供分类、字段和抽取规则。原始范文、完整原句、完整原段、用户项目的措辞对照及未经授权的专有术语摘录，保存在使用者自己的私有库。公开条目只有在来源允许公开且引用范围合适时才附短引文；否则保存抽象功能与私有来源编号，不把无法公开的原文改写成虚假的“原句”。本目录目前没有已收录的范文条目，空白模板不能冒充完成拆解的语料库。
